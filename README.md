# 🧮 Simple Python Calculator

A command-line interface (CLI) calculator built with Python that performs basic arithmetic operations.

## ✨ Features

- ➕ **Addition** (`+`)
- ➖ **Subtraction** (`-`)
- ✖️ **Multiplication** (`*`)
- ➗ **Division** (`/`) with division-by-zero validation
- 🛡️ Input error handling for non-numeric values

---

## 🚀 How to Run

1. Make sure you have Python 3 installed.
2. Run the script:
   ```bash
   python calculator.py
   ```
3. Follow the on-screen prompts to select an operation and enter numbers.
